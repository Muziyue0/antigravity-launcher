# 故障排查

| 提示 | 含义与下一步 |
|---|---|
| Google HTTPS 失败 | 网络或节点连接问题；网页测试通过也不保证模型可用 |
| 地区拒绝 | 模型服务当时拒绝该请求的地区；可验证备用，但工具无法改变官方政策 |
| 登录失效 | 停止换节点，使用官方 CLI 登录；授权码仅在官方窗口输入 |
| 资格/验证/权限 | 按官方账号提示处理；更换节点不保证有效 |
| 额度/限流 | 停止换节点，检查官方用量或等待恢复 |
| 模型配置错误 | 核对 CLI 模型标识，与桌面当前选择保持一致 |
| 超时 | 结果未确认，单次上限 60 秒；不把超时直接当作永久不可用 |
| 路由证据不足 | 即使出现 AGY_OK，也不宣布该候选通过 |
| proxy-providers | 当前只支持内联节点，不自动读取订阅或转换提供器 |
| 无法初始化 | 检查配置向导、数据目录权限和完整构建目录，可用 `--configure` 重设 |

先保存工作、正常退出已有 Antigravity，再通过启动助手进入。CLI 验证通过后，桌面仍需实际对话确认。如果运行中再次报错，停止当前生成，再使用“验证备用并重连”；全部失败会保留原连接，不会宣布修复。

定期检查默认关闭。正常每小时约为 6 / 2 / 1 次当前节点模型请求（对应 10 / 30 / 60 分钟）；发生明确地区故障时，一轮最多可能发起当前节点 1 次、备用 6 次和切换后 1 次。并发取消不保证免额度。token 汇总仅为本启动器进程已收到的 CLI 统计，不是实际账单或额度百分比。

反馈前从托盘菜单导出固定字段诊断，描述发生在哪一步、是否更换模型、是否直接重开过客户端。不附带原始 YAML、订阅链接、账号页面或浏览器授权码。
