# 后续方向

公开测试版先收集 Windows 上首次配置、代理实例隔离和运行中恢复的真实反馈，再决定稳定版发布。

优先完善：

1. 在多台电脑完成官方 CLI 自行登录、真实模型与桌面对话、故障恢复的人工验证。
2. 发布独立升级工具，校验完整包、检查客户端运行状态、备份入口并支持明确回退。当前公开构建不是个人旧版的自动升级安装器。
3. 在用户同意与不泄露订阅的前提下评估更多有效配置来源和 provider 支持。
4. 研究可靠的桌面错误信号，降低定期付费模型检查的必要性；不读取账号凭据、不拦截 TLS、不把流量安静误判为任务空闲。
5. 依据反馈改进无障碍、缩放、状态展示与本地 CLI 用量提示。

不承诺绕过官方政策、改变账号资格、获得额外额度或让任何节点永久可用。
