# Antigravity 启动助手

为 Windows 上的 Google Antigravity 提供代理检测、验证启动与运行中连接恢复。

**社区项目，与 Google、Antigravity 或 Clash/Mihomo 无官方关联。当前版本：`v1.10.0-beta.1`，供测试使用。** 工具无法更改 Google 的地区政策、账号资格或额度，不能保证任意节点或全部模型可用。

## 能做什么

- 自动发现常见安装位置，首次运行通过中文向导确认实际路径。
- 使用已有可信 Mihomo 内核建立独立的本地代理，不切换 Clash 的节点、系统代理或 TUN。
- 优先测试上次成功节点，三个并行、最多六个候选滚动补位；首个通过后启动桌面客户端。
- 分层检查 Google HTTPS、条款页地区提示和官方 Antigravity CLI 的真实模型回复。网页地区仅供参考；只有 `AGY_OK` 和本候选的代理连接证据均通过才算 CLI 验证成功。
- 支持托盘、重复启动处理、取消和客户端退出后的辅助进程清理；不会强杀正在工作的客户端。
- 使用中报错时验证备用，保持本地端口和客户端窗口，按用户确认重连旧模型连接；切换后再次验证，失败尝试回退。
- 可选定期模型检查，10 / 30 / 60 分钟，默认关闭。诊断导出只包含固定的脱敏字段。

## 使用前准备

1. Windows x64，安装 .NET Framework 4.8；本地主要测试环境为 Windows 11。尚未验证 ARM64 或其他操作系统。
2. 已安装 Google Antigravity，并具备符合官方要求的账号和网络环境。
3. 已安装可信 Mihomo 或 Clash Verge Rev。当前只支持有效配置里的内联 `proxies`，**暂不支持 `proxy-providers`**，其他客户端需要手动选择内核与有效配置文件。
4. 首次向导可从官方更新服务下载 Antigravity CLI，保留 HTTPS 证书校验并核对 SHA-512；项目不附带 CLI、代理内核、订阅或节点。

> **额度提示：检测会发送真实模型请求，会消耗额度。** 极短回复不代表几乎免费。失败、并发取消也可能有未报告的消耗；CLI 报告的 token 数不是账单总额。

## 获取与运行

目前提供源码和 CI 构建流程，尚未发布正式安装版。请只下载你核对过的本仓库构建产物，不使用来历不明的重打包。

在项目目录使用 PowerShell 构建（不需要 Python、Node 或 NuGet 包）：

```powershell
.\scripts\Build.ps1
.\scripts\Test.ps1
```

构建后运行 `dist\Antigravity代理.exe`，完整保留整个 `dist` 目录。**首次配置会下载较大的 CLI，耗时取决于网络；不包含在日常启动的等待时间内。** 不承诺 30 秒内完成真实模型验证：单次模型请求最多 60 秒，30 秒只提示继续等待。

首次运行请确认三个路径，下载并校验官方 CLI，然后保存。使用“官方 CLI 登录”自行完成认证；浏览器给出的授权码只粘贴到官方 CLI 登录窗口，**不要粘贴到模型输入框、Issue 或聊天中**。

日常双击固定入口，验证通过后启动 Antigravity。CLI 模型应与桌面当前模型保持一致；留空代表 CLI 默认模型，通过检测不等于所有桌面模型可用。客户端收到真实回复后再点击“已收到桌面真实回复”。

已有客户端运行时，请先保存并正常退出，再从启动助手启动。直接从原始图标重开客户端，可能不会继承本启动器设置的代理环境。

## 使用中报错

从托盘打开窗口，停止当前生成，点击 **“使用中报错：验证备用并重连”**。程序最多验证六个备用候选，通过后在原本的独立代理端口上再次测试模型，随后重连特定旧模型连接。窗口与客户端进程保留；正在传输的模型请求可能中断，需要回客户端重试。

定期模型检查默认关闭，勾选后按所选间隔测试。只有明确地区拒绝才触发自动备用验证；自动切换保留已有连接，新连接使用新节点。旧长连接仍可能报错，需要手动重连。账号、登录、额度和未知错误会停止无效换节点。更多说明见 [故障排查](docs/troubleshooting.md)。

## 数据与隐私

新安装的数据保存在 `%LOCALAPPDATA%\AntigravityLauncher\profiles\<安装路径摘要>\`，与程序版本分离。兼容已有“版本 / 共享”布局时保留其共享用户数据，不自动复制到仓库。`AGY_LAUNCHER_DATA` 可指定独立的绝对数据目录，用于测试或便携部署。

- 设置记录本机程序与配置文件路径，不存储账号密钥。
- 成功节点名称仅保存在本地状态文件；公开日志使用节点指纹。**本地完整日志和配置仍不建议直接上传。**
- 运行时节点配置含代理连接信息，放在限制访问权限的临时目录；正常退出后清理。异常进程退出会通过 Windows Job 关闭辅助进程，硬断电等情况可能留下私有临时文件。
- “导出脱敏诊断报告”只输出版本、固定错误类别、本进程请求次数和已报告的 token 数，不读取原始日志或凭据存储。
- 程序不提供遥测和自动上传。CLI 自身的行为受官方软件及其隐私政策约束。

关闭主窗口会收进托盘。完全退出启动助手会关闭独立代理，影响仍在使用该代理的客户端网络；请先保存工作并正常退出客户端。

## 验证与贡献

纯离线回归：`scripts\Test.ps1`。可选真实 Mihomo 本地集成测试：

```powershell
.\scripts\Test.ps1 -Integration -CorePath 'C:\path\to\trusted\mihomo.exe'
```

集成测试使用合成的回环节点和本地隧道，不读取你的订阅、不调用模型、不修改系统代理。CI 只运行离线测试，不需要账号、节点或模型额度。**离线通过不等于真实 Google 地区错误已修复**；当前公开版本尚需更多电脑、CLI 版本与桌面真实对话验证。
